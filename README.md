# AI 技能集 · AI Skills

> 一套给 AI 用的技能集合 / A collection of AI skills I built for knowledge & workflow automation.

这是我在日常使用中逐步整理的 AI 技能集合。这些技能把一些**重复性、可复用的 AI 工作流**沉淀成标准化的、可随时调用的能力，让"换一个 AI / 换一台设备"也能快速上手。

## 🎉 首个产品发布

| 产品 | 说明 |
| --- | --- |
| [**能力系统 1.0**](https://github.com/data2579/capability-system) | 让 AI 把学到的知识归档成**系统性的个人知识库**：Obsidian 双链 + 十四种能力 + 八大组件，不重复、不硬归、不编造。已发布 [v1.0.0](https://github.com/data2579/capability-system/releases/tag/v1.0.0) |

## 其他技能

| 技能 | 一句话说明 |
| --- | --- |
| `content-rewrite` | 提取个人 IP 口吻，改写口播 / 短视频 / 社媒文案，去 AI 味 |
| `asset-evolution` | 维护"关于我的知识"进化系统（记录、进化、迁移、适应度测试） |
| `doc-convert` | 本地把 docx / pdf / pptx / xlsx / 音视频转成 Markdown，便于理解与归档 |
| `handwritten-diary-ocr` | 手写日记 / 纸质笔记电子化：PDF 切页、视觉 AI 转写（带颜色标注）、校对 |
| `wechat-chat-extract` | 提取微信群聊文字内容（屏幕所见文字，语音 / 视频 / 图片拿不到） |

## 目标

把这些"为我个人定制"的流程，沉淀成一套**可复用、可迁移**的 AI 技能库；同时也分享给有同样需求的人。

## 说明

- 每个技能是一个标准目录，含 `SKILL.md`（使用说明）与可选引用 / 脚本 / 模板。
- 内容随使用持续迭代，会不定期补充。
