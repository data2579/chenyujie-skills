## 说明

- 每个技能是一个标准目录：`SKILL.md`（给 AI 读的流程、红线与验收标准）＋ 可选 `scripts/`、`references/`。
- **默认本地运行、不上传数据**；任何需要调用云端接口的步骤都会显著写明，并要求先取得用户同意。
- 密钥一律只从环境变量读取，不写进文件、不打印。
- 内容随使用持续迭代，会不定期补充。
