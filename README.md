# chenyujie-skills

> 陈昱杰 · AI 技能集 / A collection of AI skills I built for knowledge & workflow automation.

这是我（陈昱杰）逐步整理的 AI 技能集合。这些技能把一些**重复性、可复用的 AI 工作流**沉淀成标准化的、可随时调用的能力，让"换一个 AI / 换一台设备"也能快速上手。

## 现有技能

| 技能 | 一句话说明 |
| --- | --- |
| `chenyujie-content-rewrite` | 提取 IP 口吻，改写口播 / 短视频 / 社媒文案，去 AI 味 |
| `chenyujie-asset-evolution` | 维护"关于我的知识"进化系统（记录、进化、迁移、适应度测试） |
| `chenyujie-doc-convert` | 本地把 docx / pdf / pptx / xlsx / 音视频转成 Markdown，便于理解与归档 |
| `chenyujie-handwritten-diary-ocr` | 手写日记 / 纸质笔记电子化：PDF 切页、视觉 AI 转写（带颜色标注）、校对 |
| `chenyujie-wechat-chat-extract` | 提取微信群聊文字内容（屏幕所见文字，语音 / 视频 / 图片拿不到） |

## 目标

把这些"为我个人定制"的流程，沉淀成一套**可复用、可迁移**的 AI 技能库，作为对外的一张技术名片；同时也分享给有同样需求的人。

## 说明

- 每个技能是一个标准目录，含 `SKILL.md`（使用说明）与可选引用 / 脚本 / 模板。
- 内容随使用持续迭代，会不定期补充。
