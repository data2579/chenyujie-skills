# 可粘贴提示词（给 Codex / GPT / 其他 AI）

用法：把 `<...>` 换成真实路径后整段粘贴。对方不需要看本技能文件，也能按同一套流程干活。
**一轮只做 30 分钟**，做完等用户说"继续"。

---

```
把这段长课程做成"逐段分析 + 查缺补漏"，不要只做一份摘要。

素材：<视频/音频绝对路径>
本轮范围：先做 <00:00—30:00>，共 6 段，每段 5 分钟
我已有的总结在：<旧笔记目录>；AI 归档区在：<归档目录>
归档去向：<知识库/目录>；人工笔记库只读，不许改。

要求：
1. 取得真材料再写：本地转写（faster-whisper / 本地工具，不许上传到任何外部服务），
   每 5 分钟一段；每段起点抽一帧画面用于核对课件。转写保留识别原貌，
   近音错字只在整理层按课件规范化。
2. 每段固定写三块：
   - 课程内容：这段讲了什么，带时间戳（写成"约 HH:MM—HH:MM"）
   - 分析：成立什么、依赖什么条件；哪些是讲者的类比或主张，不能当事实
   - 对照与处理：我旧笔记里有吗？→ 复用 / 补一条（写明落到哪个步骤）/ 明确不建（给理由）
3. 段末还要给：查缺补漏对照表（旧节点｜已有内容｜本次处理）、AI 操作化
   （挂到具体流程步骤，挂不上写"待挂接"，不许编步骤）、适用条件、
   后续停点（下次从几分几秒继续，必要时回听衔接处）。
4. 证据纪律：讲者自述的成效/首创/个人经历不作规律；课件里显示了但口述没讲到的提纲，
   不算"已讲内容"；历史事实要对可查来源核对，发现错误写"错误说法 → 正确说法 + 依据链接"；
   识别不稳的数字和专名不写精确值。
5. 归档：写 来源说明（原文件路径/大小/时长、累计范围、取得方式与局限、抽帧定位、
   读了哪些旧笔记、历史纠错）＋ 分段补漏正文。改动前把要改的文件备份，改动清单落盘。
6. 汇报里必须写清：本次补了什么、证据局限（机器转写、未逐句听校、哪些是 AI 补充）、
   下次从哪继续。不要夸大完成度。

先告诉我你打算怎么做（取材方式、旧笔记范围、预计产出哪些文件），确认后再动手。
```

---

## 变体：只给链接（网络视频）

把素材那行换成：

```
素材：<视频链接>
```

并追加：

```
网络视频先用现成的转写工具取文稿；如果它的分段不够 5 分钟粒度，
再用本地工具对下载后的文件按 5 分钟切段。
```

## 变体：本地没有 whisper 时

```
如果没有本地转写工具，先如实说明，并给出选项：
① 我装本地工具；② 你先用现有工具做粗转写，我来校对。
不要改用上传外部服务。
```
