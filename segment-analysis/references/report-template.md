# 逐段分析报告模板（照抄结构，不要照抄内容）

> 用途：每轮 30 分钟（6 段）产出一份报告。

## 一、文件头（YAML）

```yaml
---
id: <课程代号>.lesson<N>.analysis.<起始>-<结束>   # 例：courseA.lesson1.analysis.0000-3000
type: knowledge
status: proposed
created: '<YYYY-MM-DD>'
origin: source
sources:
  - location: <来源说明文件相对路径>
    locator: '<00:00—30:00；六段机器转写与抽帧，正文时间约值>'
bindings:
  - system: <体系名>
    system_note: <体系入口页>
    component_note: <组件页>
    role: <关键原理|判断|技巧|心法|反馈>
    step: <S1|S2|...>
    process_note: <流程总览页>
    step_note: <步骤页>
    relation: <grounded_in|routes_to|improves|provides_evidence_for>
---
```

## 二、正文骨架

```markdown
# <课程>第<N>课：<起>分钟至<止>分钟分段分析与补漏

<一段总述：本段讲什么、用户旧总结已抓住什么骨架、本次重点补什么。>
<阅读方式、转写局限、已读旧笔记范围与历史纠错统一见来源说明（给链接），
并声明"以下均为整理后的转述，不是逐字引文"。>

## <00:00>—<05:00>：<这段的小标题>

**课程内容**：<带时间戳的转述；时间一律写成"约 HH:MM—HH:MM"。>

**分析**：<这段成立什么、条件是什么；哪些是讲者类比/主张而非事实。>

**对照与处理**：<旧笔记／既有节点里有没有？→ 复用 / 补一条（写明落到哪一步）/ 明确不建并给理由。>

（这一段若有独立可复用的新要点，可加 **新增要点** 小节，但仍要接 **对照与处理**。）

## <05:00>—<10:00>：……
（同上，逐段重复）

## 查缺补漏对照表

| 原笔记或既有节点 | 已有内容 | 本次处理 |
|---|---|---|
| <节点名> | <已有写法> | <复用／补什么／不建+理由> |

## 放到现有流程里怎样用（AI 操作化）

**<步骤ID> S1：<一句话要做什么。>** <具体检查项。若为 AI 补充，明写"此分支为 AI 补充，非讲者逐字流程"。>

**<步骤ID> S2：<一句话要做什么。>** <具体检查项。>

**适用条件**：<目标与结果可描述、中间过程可观察…；不适合用来保证什么。>

## 归属与返回

<体系入口 · 组件 · 步骤 · 实例 · 其他受影响页面，全部给双链。>

## 后续停点

下次从 HH:MM 继续；必要时回听 HH:MM 附近衔接句。
本次不预先总结后续内容，不把未展开的课件提纲当作新流程。
```

## 三、来源说明页骨架

```markdown
---
id: source.<课程代号>.lesson<N>
type: source
status: partial
created: '<YYYY-MM-DD>'
---
# <课程>第<N>课来源说明

- 原文件：`<绝对路径>`，<字节数>，时长约 <HH:MM:SS>。原地保留，未重复复制视频。
- 累计范围：<已分析到哪；后面未分析，不标记为已学完。>
- 取得方式：本地 faster-whisper（模型/设备/参数）；逐段阅读并与抽帧对照；
  不是逐秒观看，也未逐句人工听校；没有上传外部服务。
- 保存状态：<保存了什么；近音错字在整理层如何规范；哪些内容不做精确引文。>
- 讲者署名：<怎么称呼讲者，依据是什么；不采用画面广告水印作作者信息。>
- 课程观点、课上假设例子、AI 操作化建议、外部事实核查分开记录；归档不等于方法已有效。

## 画面定位
<HH:MM（链接到 画面-<秒>秒.jpg）：画面在讲什么。>

## 本次读取的既有总结
<实际读取了哪些文件、哪些页。>
"已覆盖/待补"仅相对于以上实际读取和相关目录关键词检索，不声称穷尽所有历史笔记。

## 历史叙述核查（<日期>）
<发现的事实错误 → 正确说法 + 依据链接。明确"此核查只纠正 X，不据此裁定全部内容"。>

## 返回整理
<本页对应的分段补漏页链接。>
```

## 四、交付汇报格式（聊天里给用户看的那段）

```
已完成 <起>—<止>，六个约 5 分钟段落，并对照旧笔记补入归档区，人工笔记库未改。

主要补充：
- <补点1：一句话，说"多知道了什么"，不说"我做了哪些步骤">
- <补点2>
- <补点3>
- <补点4（可选）>

[查看分段分析与补漏报告](<报告文件绝对路径，正斜杠>)

本次依据本地音频转写和课件抽帧核对，未逐句人工听校；识别局限已记录。下次从 **<HH:MM>** 继续。
```

**硬要求（不许省）：**

1. **必须给可点击链接**，指向**真实存在**的文件（写完先确认文件在不在）；
   路径用绝对路径＋**正斜杠**。主产出一条链接，次要文件放随后一行，别堆成一大串。
2. 开头一句说清三件事：**做完了哪段范围**、**补到哪里去了**、**人工笔记库未改**。
3. "主要补充"只写**真正新增、用户能拿去用的判断**，3–4 条，每条一行；不写过程。
4. 结尾一句写**证据局限** ＋ **下次停点**（加粗 HH:MM）。
5. **不夸大完成度**：没做的就说没做；"归档"不等于"已生效"。
